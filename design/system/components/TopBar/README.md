# TopBar

The top of an area screen: the Home button on the left, an optional text action on the right, and the screen title in `t-title-1` beneath.

## Use
- Home is a 44 pt `house` symbol in `ink`, no fill; on the camera it sits on a `surface` disc so it reads over the photo.
- The right slot takes one text button (`t-headline`): "Finish", "Sources", "Done".
- Titles say what the screen holds now: "This week", "Resting HR", "Tue, Oct 21". Not the area name.
