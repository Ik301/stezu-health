# PillButton

The app's button: a capsule at least 50 pt tall with a `t-headline` label; primary is `invert`, secondary is `surface-raised`, outline is a 1 px border in the current text colour.

## Use
- Primary for the one committing action on a screen or sheet: "Log", "Save", "Connect Apple Health".
- Secondary for everything else that is a button: "Sources", "History", "Import program".
- Outline on top of `invert` (the logger's BW toggle, rest buttons) and for add-on blocks ("+ Abs").
- Small (44 pt) only inside a GlanceCard or a toolbar.
- Labels are verbs or the thing itself, sentence case, no full stop.

## States
Disabled at 40% opacity (v1's Undo). Focus ring: 2 px `focus`, offset 2 px.
