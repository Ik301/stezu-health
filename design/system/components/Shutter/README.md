# Shutter

The Food camera's one control: a 74 pt `on-camera` ring with a filled disc, centred in the bottom bar over `camera`.

## Use
- The bottom bar holds History (left), the shutter (centre) and an empty 64 pt slot (right) so the shutter stays centred.
- In Barcode mode the shutter goes away; the scanner reads on its own.
- Disabled (camera denied) at 40% with the denied message above it.
