# EmptyState

What a screen shows before it has anything: one sentence on what will appear and why, and the one action that fills it.

## Use
- Data before Health is connected, History before the first meal, Workout before a program is imported.
- Body copy in `t-body`, a short list of what is read and written, one primary pill.
- Nothing is asked at app launch; the first open of the area is the moment.
