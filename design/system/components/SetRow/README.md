# SetRow

One logged set under the logger: number, weight x reps, and last time's numbers for that set, so progress is visible without a chart.

## Use
- Grid: set number, "135 x 8" in `t-subtitle`, last numbers in `t-label`/`muted` at the end.
- The next set shows as a dashed row with only last time's numbers: what to beat, not a target.
- Newest set sits directly under the logger, so Undo (in the logger's menu or the toast) always refers to the row in view.
- Weight shows "BW" for bodyweight, never 0.
