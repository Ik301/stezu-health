# RangeValue

How an estimate is written: low to high with an en dash and a small unit, never a single midpoint that pretends to be exact.

## Use
- Food energy and protein are always ranges: "620–780 kcal", "92–118 g". Sums add lows and highs.
- Measured values are single numbers with their unit: "172.4 lb", "57 bpm".
- A derived value carries its confidence beside it: a Tag with the level and the reason ("5 weigh-ins").
- Absent is "--" in the same style as the value would have been. Never 0, never blank.
- Thousands get a comma; units are lower case and spaced: "8,140 steps", "7h 12m".
