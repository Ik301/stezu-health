# Hypnogram

Last night's sleep as four lanes, Awake, REM, Core and Deep, from bedtime to wake, with the stage totals underneath.

## Use
- Each stage has its own row and label, so the chart reads without colour; colours run dark (deep) to light (REM) with `sleep-awake` the one warm hue.
- Totals under the chart in `t-stat`, each with its stage name. Time asleep excludes Awake.
- Only drawn when the source writes stages to Health. When it writes only "asleep" or "in bed", show one bar and say "Stages not recorded by <source>".
- Labelled `context`: sleep is shown, never scored.
