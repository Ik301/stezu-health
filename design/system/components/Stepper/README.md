# Stepper

A big value between - and + circles: the only way to change a number while logging, so the keyboard never opens.

## Use
- Weight, reps and the weigh-in. The value is `t-big` with a small unit; the buttons are 48 pt outline circles in the text colour of their surface.
- One tap is one step: the exercise's step for weight (default 5 lb), 1 for reps, 0.1 lb for a weigh-in. Press and hold repeats.
- Prefill from the last time, so the usual case is zero stepper taps.
- A stepper that cannot move (bodyweight) dims its buttons to 40% and shows "BW".
