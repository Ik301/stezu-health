# UndoToast

A short-lived `invert` capsule that confirms a one-tap action and offers Undo, so one-tap actions never need a confirmation dialog.

## Use
- After Log on a meal, Finish on a workout, Save on a weigh-in. Text says what happened and where it went: "Lunch logged, in Health".
- Stays 5 s, or until the next action. Undo reverses the local save and the queued sync record.
- Place it just above the bottom bar, inside the thumb zone.
