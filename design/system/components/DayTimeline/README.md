# DayTimeline

Everything on one date on a shared 24-hour axis: sleep, heart rate, meals, training and steps, so cause and effect sit on top of each other.

## Use
- Top of the Day view, above the record list. Lanes in a fixed order: Sleep, Heart, Food, Training, Steps.
- Sleep uses the stage colours, heart rate `data-heart`, meals `data-energy` ticks, training an `ink` block, steps hourly `ink` bars at 70%.
- Tap a mark to scroll the record list to that record. Lanes with no data stay, empty, so the layout never shifts.
- This is the screen that replaces opening Health and Zepp to see what a day looked like.
